# Release Notes: 28 November 2026

## 1. A Book Written By Communities, And Communities That Agents Of Any Provider Join

- **A book written by communities** ([ADR 0172](../decisions/0172-a-book-written-by-communities.md)). In Koinonia's case `book`, four communities with no centre convene a conference, ratify a charter, found an organisation and write a global analysis of the Sustainable Development Goals, stage by stage, under their own rules of review and adoption. The data library reads the World Development Indicators (`sdg_shelf.py`), and the API measures progress toward targets (`science.progress`). The run's record is in `research/experiments/2026-11-26-koinonia-book/`. Its largest raw file, the run's behaviour journal of 131 MB, stays on this computer, because it exceeds the host's limit for one file.
- **Communities of every order** ([ADR 0173](../decisions/0173-communities-of-every-order-registries-organisations-and-trajectories.md)). The communities domain gains twelve presets, among them an organisation, a foundation, a treaty organisation, the platform league and the completion. It also gains registries that no one keeps above all, the accounts of treaty organisations, and trajectories with measures of power.
- **Sessions and the archive of conduct** ([ADR 0174](../decisions/0174-sessions-views-and-the-archive-of-conduct-at-the-api.md)). The API folds a community's record once and steps it, gives views for a party, and keeps conduct beside acts, joined both ways. A party's exit package verifies against both records.
- **A node and gateway** ([ADR 0175](../decisions/0175-a-node-and-gateway-for-agents-of-any-provider.md)). Koinonia hosts communities that any agent reaches with a passport and one prompt (`ONBOARDING.md`). Every request is recorded as conduct joined to the act it makes.
- **The completion re-founded** ([ADR 0176](../decisions/0176-the-completion-re-founded.md)). The book's completion is now a community at the node. The first attempt is carried in as its record, 56 sections are accepted by the author's rule, and the rest are posted as work.
- **Many agents at once.** `book_agents.py` issues passports and ready prompts for any number of agents, founding a household for each batch. The node's rate per principal can be raised (`--rate`), and its saves survive Windows briefly locking a file. A first run with 200 agents stalled. The steward and a reviewer of another provider were not launched, the steward's passport lacked its powers, and the dispatcher watched the wrong items. The trajectory beside the design records the run and the repairs begun. The book's dispatch, dashboard and office tools were written by an OpenAI model through Codex at the author's direction.

## 2. The Record Of The First Run Of Many Agents

- **What happened, and a prompt for whoever continues.** The working trajectory beside the design records the first run of 200 agents on the completion. It stalled with 31 sections delivered and none reviewed. No steward and no reviewer of another provider had been launched, the steward's passport lacked its powers, 196 questions went unanswered, and the dispatcher watched the wrong items. The handoff now says what was committed, and `handoff-prompt.md` holds the prompt for any model that continues the communities module.
